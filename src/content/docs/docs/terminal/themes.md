Verified on macOS only.

The application has a dark and a light theme, and the terminal pane follows whichever is active. Terminal colours come from a hex palette tied to the theme, so switching the application theme restyles running shells immediately.

Font family, size and cursor style are terminal settings and apply live.

:::note[Planned]
A design token set, several polished dark and light themes, high-contrast variants, and terminal themes as an importable format separate from UI themes are milestone 1 and milestone 11 work still open. See the [roadmap](/roadmap/).
:::
