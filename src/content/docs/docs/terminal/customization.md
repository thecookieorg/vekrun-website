## Terminal settings

Open Settings, then Terminal. Font family and size, cursor style, scrollback length, default shell and command details apply immediately to running shells.

## Themes

Vekrun has a dark theme and a light theme, and the terminal follows whichever is active. Switching the application theme recolors running shells at once.

:::note[Planned]
More themes, high-contrast variants, and importable terminal color schemes separate from the application theme are planned. See the [roadmap](/roadmap/).
:::
