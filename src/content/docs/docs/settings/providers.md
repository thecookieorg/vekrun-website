Settings, then Providers, lists every connection.

- **Add** a provider with your API key and press **Test** to check it with a live request.
- **Local runtimes** show whether Ollama or LM Studio is installed and whether it is running, as two separate facts.
- **Remove** a connection to delete its key from the keychain.

Each provider's models are listed with what Vekrun knows about them: context size, tool support and price where published, and "unknown" where not.

Usage is tracked per session, project and task. Vekrun's own estimate cannot cap a provider's actual bill unless the provider offers that control, and the interface says so.

See [Connecting AI](/docs/getting-started/connecting-ai/) and [Choosing models](/docs/ai-coding/choosing-models/).
