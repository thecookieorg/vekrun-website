This page is history. The current plan is the [roadmap](/roadmap/), organized around the AI Factory. Below is the engineering view that built the development build: one complete 1.0, delivered through twelve milestones. A milestone has two states worth separating. **Implemented** means its code is merged on the main branch with tests. **Closed** means its acceptance checklist, the gate, has passed on macOS, Windows and Linux. A milestone can be implemented with its gate still open, and the notes say when that is the case. A screen existing is not a feature existing.

Automated checks ran on all three platforms during the first milestone (October 2026). They are paused at the moment, so work merged since then has been verified by hand on macOS only.

## Dependency order

M1 first. M2 (terminal), M3 (providers) and M5 (workspaces, Git, editor) can proceed in parallel after it. M4 (single-agent coding) needs M3. M6 (Factory) needs M4 and M5. M7 (verification and integration) needs M6. M8 (control plane, workers, APIs) and M9 (routing, budgets, scheduling) need M7. M10 (extensibility and MCP) needs M8 and M9. M11 (polish) needs everything functional, and M12 (hardening and release) needs M11.

## Release gates

Twelve demonstrations must pass with recorded evidence before 1.0: terminal offline; a direct API model; a local model offline; plan, implement, verify, approve; a Factory run where an independent verifier catches a seeded defect; queue and audit surviving a restart without unsafe replay; remote worker reconnect; a user-defined agent API; a scheduled workflow with disclosed requirements; credential and data deletion; malicious repository text unable to override policy; and install, shells and update on all three operating systems.
