The Board shows your tickets in four columns: To Do, In Progress, In Review and Done. In the development build the tickets come from a local list; connected trackers are [planned](/docs/board/connecting-a-tracker/).

## Ticket cards

A card shows the ticket's identifier, title, priority and status, plus what Vekrun is doing with it: a worktree opened, an agent at work, tests running, changes waiting for review.

## Ticket details

Select a card to read the full description, acceptance criteria and links, and to see the branch, worktree and sessions attached to it.

## Linking a ticket to a repository

A ticket needs to know which repository it belongs to before Start Work can branch. Set it on the ticket; with connected trackers, a project-to-repository mapping will do this for you.

Each repository has a branch-name template and a worktree location you can change in Settings.
