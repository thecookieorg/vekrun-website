Vekrun opens to a terminal. In the development build the window has a project picker in the top bar and primary areas for Terminal, Code, Agents, Board, Plan, Council, Factory and Git. Areas that are not finished say so in the interface instead of showing an empty screen.

## Start with the terminal

The terminal works with no AI connected and no network. Open a tab, run your shell, split the pane with `⌘D`. Nothing about ordinary shell use waits on a model.

## Pick a project

Use the project picker in the top bar to open a folder. Vekrun remembers it, and every new shell starts there. See [Opening a project](/docs/getting-started/opening-a-project/).

## Connect an AI when you want one

AI is optional. When you are ready, add a provider key or point Vekrun at a local model; see [Connecting AI](/docs/getting-started/connecting-ai/). Skipping this step is a complete, supported way to use Vekrun.
