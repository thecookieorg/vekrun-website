A Factory job works on a repository you have imported.

## Ways to import

- **Clone by URL.** Paste the address of any repository you can access: a private company repository or an open-source project you do not own. No fork is required.
- **Open a local repository.** Pick a folder that is already on your machine.

:::note[Planned]
Browsing your GitHub and GitLab repositories from inside Vekrun, and **Fork & Clone** for contributing to a project upstream, are planned. See the [roadmap](/roadmap/#environments).
:::

## What the project gives a job

- Its languages, package managers and instruction files, read before the first plan.
- Its Git branches, worktrees and changes.
- A link from Board tickets to the repository, so a job knows where to branch.
- Its Engineering Memory: past decisions, jobs and evidence.

## Several projects

Import as many projects as you like. Jobs in different projects run side by side within the limits you set.
