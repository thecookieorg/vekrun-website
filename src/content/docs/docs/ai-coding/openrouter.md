OpenRouter gives you many models behind one API key. Vekrun supports it in two stages.

## Basic connection today

Add OpenRouter as an OpenAI-compatible endpoint with your own key. The key is stored in your operating system's keychain, and the connection can be tested, replaced and removed like any other provider. Models you name explicitly work in coding sessions, plans, Council, Factory runs and reviews, and OpenRouter bills you directly.

See [Choosing models](/docs/ai-coding/choosing-models/) for how the OpenAI-compatible connection works.

## Dedicated integration, planned

:::note[Planned]
The dedicated OpenRouter integration is approved scope and not built yet. None of the capabilities below work today. See the [roadmap](/roadmap/).
:::

- Automatic model discovery with names, descriptions and context windows.
- Pricing shown per model, with budget enforcement using the existing limits.
- Filtering by capability, such as tool calling or image input.
- Favourites and compatible fallback models.
- Provider routing and privacy restrictions, so a request only goes where you allow.
- The same model choice available in Plan, Council, Factory, reviews and Insights investigations.

Direct connections to Anthropic, OpenAI and Google stay available. OpenRouter is never required.
